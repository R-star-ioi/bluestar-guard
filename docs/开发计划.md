# 《蓝星守卫》微信小游戏 · 开发规划

> 类型：割草生存 × 塔防布阵 × 英雄合成（灵感参考《永远的蔚蓝星球》）
> 平台：微信小游戏（同时提供浏览器预览版，方便随时试玩调试）
> 版本：v0.1.0（首个可玩版本）

---

## 1. 一句话概述

控制主角在星球基地周围跑动割草，敌人一波波冲击基地水晶；击杀敌人掉落**金币**与**经验**——金币用来**招募英雄 / 合成英雄 / 强化英雄 / 修复基地**（塔防布阵），经验升级后**三选一随机技能**（Rogue 成长），每 5 波一个 Boss，活得越久分越高。

## 2. 核心玩法循环

```
移动躲避/拉怪 ──► 自动攻击割草 ──► 掉落金币◆经验
      ▲                                │
      │                                ├─► 招募英雄（随机职业，摆上阵地上）
技能三选一 ◄─ 升级（经验条满）          ├─► 拖拽两个同名同级英雄 → 合成 +1 级
      ▲                                ├─► 直接升级 / 全体强化 / 修复基地
      │                                ▼
   波次变难 ◄──────── 波清空 ─────── 每 5 波 BOSS
                        │
                  玩家死亡 或 基地被摧毁 → 结算（波次/击杀/时长 最佳纪录）
```

## 3. 系统拆解

### 3.1 操作（竖屏，单指为主）
- **全屏动态虚拟摇杆**：按住屏幕任意处拖动即出现摇杆控制主角。
- **英雄拖拽**：按住英雄拖动 = 换位置；拖到**同职业同等级**英雄上松手 = 合成升级（+1 级）。
- **点按英雄**：弹出英雄信息面板（属性 / 直接升级 / 出售）。
- 底部三个金币按钮：招募英雄、全体强化、基地修复。

### 3.2 玩家成长（升级三选一）
经验来自绿色宝石。每升 1 级暂停游戏，从技能池随机抽 3 个（已满级的不出现）：

| 方向 | 技能（每级效果） |
|---|---|
| 输出 | 攻击强化+20% / 疾速射击-8%间隔 / 分裂箭矢+1弹道 / 穿透之刃+1穿透 / 致命打击+8%暴击 / 巨型弹药弹体+30%且伤害+8% |
| 生存 | 生命之泉+30上限并回血 / 恢复光环+1每秒 / 鲜血汲取+2%吸血 |
| 功能 | 疾风之靴+10%移速 / 磁力手套+45%拾取范围 / 点金之手+25%金币 |
| 塔防协同 | 战友强化全英雄伤害+15% / 集结战鼓全英雄攻速+10% |

全部满级后提供「治愈」「赏金」保底选项。

### 3.3 英雄系统（塔防核心）
| 职业 | 定位 | 数值(Lv1) | 每 +1 级 |
|---|---|---|---|
| ⚔ 剑士 | 近战环斩(范围95) | 伤18 / 1.1s | 伤害×1.6，间隔×0.96 |
| 🏹 弓手 | 单体远程(射程330) | 伤11 / 0.55s | 同上 |
| 🔮 法师 | AOE火球(爆75) | 伤26 / 1.5s | 同上 |
| 💣 炮手 | 大范围重炮(爆110) | 伤55 / 2.4s | 同上（稀有） |
| ✚ 牧师 | 治疗脉冲(主角+基地) | 回6 / 2.0s | 回复×1.5（稀有） |

- 招募费用 25 起，每次 +8；上阵上限 9 人，围绕基地自动寻位摆放。
- 合成上限 Lv6；信息面板可花金币**直接升级**（60 起 ×1.9）或**出售**（返 20×等级）。
- 全体强化：全英雄伤害+15%（100 起 ×1.6，可叠加）。
- 英雄不会被攻击（纯塔），策略在布位与合成取舍。

### 3.4 塔防要素
- 基地水晶（地图中心，HP 800）：敌人优先攻击基地；玩家靠近敌人 190 码内会**吸引仇恨**，用于拉怪保护基地。
- 敌方射手会在射程外停下放弹幕。
- 基地修复按钮：花 80 金回 25%。

### 3.5 敌人与波次
| 敌人 | HP | 速度 | 特点 |
|---|---|---|---|
| 红色史莱姆 | 22 | 62 | 基础近战 |
| 疾行虫(3波+) | 14 | 105 | 快速脆皮 |
| 装甲胖(4波+) | 90 | 36 | 慢速高伤 |
| 毒液射手(6波+) | 34 | 50 | 远程弹幕 |
| 精英(5波+概率) | ×9 | ×0.9 | 体型×1.7，金币15/宝石8 |
| BOSS(每5波) | 700×成长 | 34 | 会召唤小怪，掉80金 |

成长公式：HP ×1.13^(波-1)，伤害 ×1.05^(波-1)（封顶3倍），预算 = 10+6波+波^1.5。
波清空后 3 秒间歇进入下一波；出生点在玩家视野外环带。

### 3.6 掉落
金币(自动磁吸拾取)、经验宝石、❤心(+25HP 2%)、🧲磁铁(全场吸取 0.8%)、💣炸弹(大范围清除 0.8%)、精英/Boss 大额掉落。

### 3.7 经济数值（初版，均在 data.js 可调）
起始金币 50（开局送 1 个 Lv1 剑士）。

## 4. 技术方案

- **纯原生 Canvas 2D，不用引擎**：包体小、零依赖、微信审核简单。
- **一套代码双平台**：
  - 微信小游戏：`game.js` 入口 + `wx.*` API；
  - 浏览器预览：`index.html` + `web/prelude.js` 提供的 `require` shim，直接 Chrome 打开即玩，方便调参试玩。
- **零美术素材**：程序化几何风（渐变/描边/粒子/屏幕震动/伤害飘字），技能卡图标用 emoji。
- 性能：敌人空间哈希网格（碰撞/索敌/分离），对象数组 swap 删除，粒子上限，逻辑 px + DPR 渲染。

```
├─ game.js / game.json / project.config.json   # 微信小游戏入口与配置
├─ index.html + web/prelude.js                 # 浏览器预览
├─ js/
│  ├─ boot.js                # 全局命名空间 G（双平台共享桥）
│  ├─ core/                  # platform(画布/触摸/存储) util input camera audio(合成音效)
│  ├─ config/data.js         # ★ 全部数值配置（改平衡只改这里）
│  ├─ entities/              # fx(粒子/飘字/光环) pickup projectile enemy hero player
│  ├─ systems/waves.js       # 波次与Boss编排
│  ├─ ui/                    # 立即模式UI：HUD、技能三选一、菜单、结算、暂停、英雄面板
│  └─ main.js                # Game 主类（状态机/系统编排/触摸路由/渲染）
└─ docs/开发计划.md
```

## 7. 风险与对策
- 性能（低端机满屏怪）：网格加速 + 数量上限 + 粒子池，必要时降 DPR。
- 数值失衡：所有数值集中在 `data.js`，浏览器版改完刷新即测。
- 微音效兼容：WebAudio 全 try/catch，失败静默不影响玩法。
